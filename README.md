# 종이비행기 시뮬레이터

브라우저에서 종이비행기를 접고, 그 모양 그대로 날려 보는 웹 앱입니다.
초·중·고 학생이 쓰는 것을 생각하고 만들었고, 화면 글은 모두 한국어입니다.

- **접기**: 3D 위에서 선을 긋고 접어요. 맞춰 접기, 포켓 접기, 자주 쓰는 접기 버튼이 있어요.
- **튜토리얼**: 접은 순서가 그대로 기록되어, 빈 종이부터 한 단계씩 따라 접을 수 있어요.
- **날려 보기**: 접은 모양에서 무게, 무게중심, 날개를 계산하고, 던지는 각도·엘리베이터·날개 각도를 바꿔 가며 가장 오래 나는 조합을 찾아 그 조합으로 100번 던져 점수를 매겨요.
- **시뮬레이터**: 던질 때마다 새로 던지는 한 번의 비행을 재생해요. 체육관 바닥 위를 날아가는 3D 장면, 그 순간의 비행기 자세(바람·힘), 수치, 이번 비행 기록과 도는 원 지름을 보여 줘요.

## 시작하기

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 배포용 빌드 (dist/)
npm run validate   # 엔진 검사 (275개)
npm run audit      # 참고 도안이 실제로 접히는지 검사
npx tsx scripts/calibrate.ts   # 책 비행기들을 목록 카드와 같은 방식으로 날려 보기 (보정 확인용)
```

## 화면

| 화면 | 하는 일 |
|------|---------|
| 목록 | 책 비행기와 내 비행기. 다섯 가지 점수(고도·트랜지션·싱크레이트·강도·밸런스)를 오각형으로 보여 줘요 |
| 접은 모양 | 3D에서 접기. 선 긋고 접기, 맞춰 접기, 겹 고르기, 좌우 대칭, 종이 돌리기, 확대·축소 |
| 전개도 | 펼친 종이 위의 산접기(빨강)·골접기(파랑)·자국과 치수 |
| 날려 보기 · 결과 | 가장 오래 나는 조정값으로 100번 던진 결과와 평가 (목록 카드와 같은 숫자) |
| 날려 보기 · 시뮬레이터 | 던지는 힘·각도·장소·엘리베이터·윙렛 꺾기·날개 각도를 고르고 **적용하기**로 한 번에 반영. **추천 튜닝 적용하기**는 가장 오래 나는 조합으로 되돌려요. 비행 단계(던짐·꼭대기·선회·활공)별 위치, 자세, 속도, 받음각, 양력·항력 |
| 튜토리얼 | 기록된 단계를 처음부터 한 단계씩 |

## 설계 원칙

- **기록 하나가 곧 비행기**: 비행기는 접기 단계 목록(스크립트) 하나로 저장되고, 모든 화면이 그 기록을 다시 계산해 그립니다.
- **진실의 원천은 하나 (SSOT)**: 목록 카드와 날려 보기는 같은 판정(`cardFlight` / `bestTuning`)을 씁니다.
  비행기마다 던지는 각도(30~90°)·엘리베이터(−30~+30°)·날개 각도(0~30°)를 모두 시험해 가장 오래 나는 조합을 찾고,
  목록·결과 점수는 그 조합으로 매깁니다. 날려 보기는 그 조합으로 열리고, '다 접었어요'를 누르면 비행기와 함께 저장됩니다.
  시뮬레이터에서 바꾸는 값은 시험이라 기록을 바꾸지 않습니다.
- **종이는 앞으로만 접힌다**: 자르지 않고, 반대쪽으로 접으려면 뒤집습니다.
- **재지 않고 계산한다**: 무게중심, 가장 잘 나는 조정값은 접은 모양에서 계산합니다.
- **던지기는 날개 수평으로**: 비행기 코 방향으로 곧게 던지고, 손의 흔들림만큼(±2°) 매번 조금씩 기울어집니다.
- **엘리베이터는 정해진 크기**: 양쪽 날개가 만나는 가운데 뒤끝에서 날개 쪽으로 1.5cm, 앞쪽으로 0.3cm. 각도만 고릅니다.
- **접은 모양은 한 번 재고, 비행은 잰 값으로**: 접은 종이 조각 더미에서 바로 날리지 않습니다.
  먼저 측정표(`aero/spec.ts`)를 만들고, 비행 계산은 측정표로 만든 등가 비행기만 씁니다.
  - 위에서 본 1mm 격자 지도: 칸마다 겹 수, 윗면·아랫면 높이, 종이 무게, 날개 폭 방향 강성
  - 동체 옆모습 지도, 날개 단면표(2mm 간격: 앞전·뒤끝, 두께, 앞전 반지름)
  - 날개 판(꺾인 각도), 접힌 모서리 목록(위치, 감싼 겹 수, 반지름, 코 말기 여부)
  - 요약값: 길이, 폭, 넓이, 무게, 무게중심, 코 두께, 동체 깊이, V각

  캠버, 두께 저항, 날개 휨은 측정표에서 읽고, 날개 윤곽·무게·관성은 등가 비행기가 가집니다.

## 저장

- 내가 접은 비행기는 **브라우저 localStorage**에 저장됩니다 (`paper-plane.planes.v1`).
  다른 컴퓨터로 옮기려면 접기 화면의 **내려받기**로 파일을 받아 두세요.
- 무거운 비행 계산 결과는 `paper-plane.flight-answers.v1`에 보관합니다.
  계산 방식이 바뀌면 `src/ui/flightJobs.ts`의 `CALC_VERSION`을 올려야 새로 계산됩니다.

## 비행 계산의 근거

비행 계산에 쓰는 공식과 상수는 공개된 자료와 대조했습니다 (`src/aero/flight.ts`의 주석에 출처가 있습니다).

| 항목 | 근거 |
|------|------|
| 운동 방정식 | 6축 강체 (위치·속도, 몸통의 코·윗면 방향, 구름·키놀이·머리 돌림 속도). JSBSim 같은 비행 시뮬레이터와 같은 오일러 방정식 |
| 양력·와류 | 와류 격자법(VLM), Biot–Savart · Kutta–Joukowski |
| 옆 방향 계수 | 동체·윙렛 옆면적(날개 위에 선 판의 양력 기울기)과 날개에서 구함 (USAF DATCOM, 띠 이론): 옆힘, 풍향 안정, 요 감쇠, 상반각 효과 −(양력 기울기/4)·Γ, 롤 감쇠 −(양력 기울기/6) |
| 윙렛 꺾기 | 윙렛 뒤끝 1cm를 얇은 날개 이론의 플랩 효율로 계산. 버드맨은 1mm 꺾으면 지름 약 20m로 돌아요 |
| 느린 공기 효과 | 느리게 날 때(레이놀즈수 수만) 날개 뒷부분 공기가 떨어져 코가 들림 (Mueller 등의 저레이놀즈 판 실험). 크기(0.015)와 사라지는 속도(레이놀즈수 7만)는 버드맨 지도서(엘리베이터 내림, 15~30초)에 맞춘 값으로, 모든 비행기에 같이 씀 |
| 날개 끝 손실 e | 0.88: 실제 종이비행기 성능에 맞춤 (기록 비행기 싱크 약 0.46m/s, 버드맨 지도서 15~20초). 알루미늄 평판 풍동값(Torres & Mueller 0.38~0.82)은 종이비행기를 두 배 빨리 떨어뜨려서 쓰지 않음 |
| 실속 뒤 | 판에 수직인 힘 하나 (Ortiz·Rival·Wood 2015, 정사각 판 1.17) |
| 마찰 | 층류 평판 1.328/√Re, 날개 두께 형상 계수 1 + 2t/c + 60(t/c)⁴ (Raymer), 휜 날개는 휜 양력 기준으로 점성 저항 (Pelletier & Mueller) |
| 얇은 날개(코의 볼록함) | 얇은 날개 이론 (Anderson) |
| 접힘 두께 | 접은 종이는 완전히 붙지 않아 겹마다 틈이 생김: 실측(유니스 길이 11.1cm)과 맞춰 보니 꾹 눌러 접은 코에는 틈이 거의 없음: 지금은 틈 0. 평량별 표(`FOLD_GAP`)는 남겨 두고 쓰지 않음 |
| 코 말기 | 말 때마다 뭉치를 반 바퀴 감싸는 데 종이가 쓰여 코 끝이 뒤로 물러남 (π/2 × 종이 두께 × 평균 겹수). 무게는 감긴 자리(코)에 그대로 남아 무게중심이 코끝에 가까워짐. 맞춤값 없이 버드맨 무게중심 2.49cm(지도서 2.5cm), 유니스 길이 11.0cm(실측 11.1cm) |
| 옆 가장자리 소용돌이 | 네모난 날개(종횡비 1~2)는 옆 가장자리 소용돌이가 양력 Kv·sin²α·cosα를 더하고, 그 힘은 시위 가운데에 걸림 (Polhamus 흡입 유추를 옆 가장자리에, Lamar). Kv는 Torres & Mueller 2004 평판 결과에서 읽은 값: 종횡비 1에서 약 4, 2에서 약 1. 받음각이 클수록 코를 숙여 정점에서 수평으로 돌아오게 함 |
| 밸런스 점수 | 받음각 0° 기울기가 아니라 실제 활공 받음각에서 잰 안정 여유 |
| 동체 벌어짐 | 손을 놓으면 동체가 약 25° 벌어져 날개가 한쪽당 12.5° 내려옴: 손에서 20°로 맞춘 V가 비행 중 약 7.5° (평평보다 아래로는 안 내려감). 양력은 벌어진 날개로, 수평으로 돌아오는 힘은 손에서 맞춘 V로 계산 (`BODY_SPREAD`) |
| 날개 강도 | 판 이론: 접힌 선으로 이어진 겹은 한 덩어리(두께³), 따로 놓인 겹은 합 |
| 던지는 힘·높이 | 나이별 공 던지기 속도 연구, 한국 성장 도표의 평균 키 |
| 손의 흔들림 | 날개 수평으로 던져도 매번 약 ±2° 기울어짐 (어림값). 완벽히 수평이면 루프 꼭대기에서 몸을 돌려 나오지 못함 |

계산을 바꾸면 `scripts/calibrate.ts`로 책 비행기 결과를 확인하고, `CALC_VERSION`을 올려 주세요.

## 알려진 한계

- 가장 오래 나는 조정값은 441개 조합을 한 번씩 날린 뒤 상위 24개를 12번씩 다시 던져 고릅니다. 비슷한 조합끼리는 그때그때 다른 쪽이 뽑힐 수 있습니다.
- 느린 공기 효과의 크기는 측정값이 아니라 버드맨 지도서에 맞춘 값입니다.
- 코의 볼록함이 만드는 힘은 얇은 날개 이론으로 계산해서, 두꺼운 코 뭉치에서는 실제보다 작게 잡힐 수 있습니다.
- 엘리베이터 효과는 각도에 비례한다고 봅니다 (크게 꺾었을 때 효과가 줄어드는 것은 넣지 않았습니다).
- 윙렛 꺾기는 윙렛 전체의 가운데 위치로 계산하고, 날개 각도를 바꿔도 윙렛 높이는 그대로 둡니다. 크게 옆으로 미끄러질 때 옆면의 실속은 넣지 않았습니다.
- 빠를 때 날개가 휘는 효과는 넣지 않았습니다 (날개 뿌리가 V로 접히는 것은 약한 날개의 문제로, 강도 점수로만 봅니다).
- 포켓 미리보기의 부푼 모양은 보여 주기 위한 근사 그림입니다.
- 비행 계산은 접은 모양으로 한 예측이라, 실제로는 접는 솜씨와 던지는 손에 따라 달라집니다.
